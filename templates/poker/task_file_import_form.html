Задачи обновляются по коду и идентификатору EVA. Заполненная оценка заменяет текущую; числовой ноль переводит задачу в «Не оценена», сохраняя историю голосования. Пустая ячейка сохраняет локальную оценку. Новые задачи без оценки попадают в бэклог и могут быть добавлены в очередь. Колонка «Спринты» обновляет назначения (пустая — исключает из текущего спринта); новые спринты создаются по точному названию. Квота берётся из «Тип квоты». Без соответствующей колонки сохранённые данные не меняются.

EVA — источник актуальных оценок и назначений. Импорт обновляет также задачи завершённых и архивных спринтов; их состав и итоговые часы могут измениться.

Разработка АБС/BE/FE и тестирование из EVA доступны для оценки после выполнения связанной аналитики. Сопоставляем точное название родителя, а при его отсутствии — название задачи без [SA]/[ABS]/[BE]/[FE]/[QA] и окончания DEV/TEST у [QA]. Учитываем проект и эпик. Импортируйте также выполненную аналитику; «Закрыта» без явного выполнения не даёт допуска.
